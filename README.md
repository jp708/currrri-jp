# Portfolio — Juan Pablo Quiros Reyes

Sitio web personal / portfolio de Juan Pablo Quiros Reyes, estudiante de Técnico en Desarrollo Web.

## Archivos

- `index.html` — Estructura de la página
- `styles.css` — Estilos (tema oscuro/claro, responsive, animaciones)
- `script.js` — Interactividad (tema, menú móvil, scroll reveal, contadores, formulario WhatsApp)
- `yo.jpeg` — Foto de portada (ya incluida)
- `favicon.ico`, `favicon-32.png`, `favicon-192.png`, `apple-touch-icon.png` — Icono de la pestaña (logo JP)
- `guion_podcast.md` — Guion de ~5 minutos para el podcast
- `podcast-voz.js` — El mismo guion preparado para que la página lo narre con la voz del dispositivo
- `assets/podcast_juanpablo.mp3` — Audio del podcast (opcional). Si existe, la página reproduce este archivo; si no, narra el guion con la voz en español del dispositivo
- `Curriculum_Juan_Pablo_Quiros.pdf` — Currículum (junto a index.html) que abre el botón “Ver currículum” (copia aquí tu archivo)

## Cómo usar

1. Mantén las carpetas tal cual (`assets/` y `yo.jpeg` junto a `index.html`).
2. Abre `index.html` en el navegador o súbelo a Vercel / GitHub Pages / Netlify.

## Características

- Diseño responsive (móvil, tablet, escritorio)
- Tema claro / oscuro con persistencia en localStorage
- Menú hamburguesa en móviles
- Animaciones de aparición al hacer scroll
- Contadores animados
- Barras de habilidades
- Formulario de contacto con validación e integración a WhatsApp
- Navegación activa según la sección visible
- Reproductor de podcast con ecualizador animado
- Botón “Ver currículum” animado con visor PDF
- Sección “Páginas creadas” con vista previa en vivo de servicio-casting, serparte-casting y osvaldo-one
- Formulario de cotización (servicio, presupuesto, plazo) que arma el mensaje de WhatsApp
- Podcast de ~5 minutos: narración automática o tu mp3 si lo agregas
- Transición rápida y suave (cortina) al navegar por las secciones y al abrir las páginas de proyectos
